# Project Hail Mary — Science Lab

Sito statico interattivo in italiano dedicato alla scienza dietro *Project Hail Mary*.

## Contenuti

- 6 moduli: astrofisica, astronomia osservativa, energetica, relatività, gravità artificiale e astrobiologia.
- Modalità spoiler: minimi, moderati, completi.
- Laboratori interattivi su legge dell'inverso del quadrato, Stefan–Boltzmann, gravità artificiale e accelerazione relativistica.
- Quiz con spiegazioni immediate.
- Progresso salvato localmente nel browser.

## Deploy

Il progetto non richiede build step. Può essere servito direttamente da GitHub Pages o da qualsiasi host statico.
